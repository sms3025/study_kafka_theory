실제 실패 재현에서 기존 멤버의 장애 판정 전에 Consumer가 유휴 제한으로 종료되는 문제가 드러나, 초기 그룹 참여 대기와 데이터 유휴 대기를 구분했습니다. classic 세션 10초/heartbeat 3초를 학습용으로 명시한 뒤 재처리와 DB 복구 시나리오가 통과했습니다.

검사 중 JAR 빌드 교체로 발생한 실행 중단은 빌드 종료 후 실행하는 순서로 재검증했습니다. 강제 종료 exit 17, Outbox rollback 오류는 의도된 장애 실험의 결과입니다.

운영 부하·보안·장시간 안정성 또는 실제 서버/디스크 장애까지 검증한 것은 아닙니다. 예제의 보장 범위와 확장 과제는 각 이론 페이지 및 최종 프로젝트에 구분했습니다.

검증 후에는 이번 작업에서 만든 컨테이너와 Kafka·DB·Streams 테스트 데이터 볼륨을 정리했습니다. 다운로드한 Docker 이미지와 Maven 캐시, 빌드한 JAR는 남겼습니다. 학습자는 `up → build → init`으로 새 데이터에서 시작할 수 있습니다. 임시 HTTP 미리보기 서버도 종료했으며 HTML은 서버 없이 직접 열 수 있습니다.
