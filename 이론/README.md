# 이론 자료 사용 방법

[index.html](index.html)을 브라우저로 여세요. 인터넷이나 로컬 서버 없이 사용할 수 있습니다.
`초급/01.html`부터 `고급/12.html`까지 순서대로 진행합니다.

각 페이지는 다음 구성을 갖습니다.

1. **개념·원리:** 왜 배우는지, 비유, 핵심 개념, 예시, 시간순 시나리오, 비교표, 함께 알아둘 개념, 핵심 정리
2. **데이터 흐름:** SVG 구조도, 단계별 재생, 일부 단원의 조작 시뮬레이터
3. **현업 패턴 코드:** 실행 가능한 Java 소스에서 가져온 발췌와 설명
4. **대응 실습:** 명령, 예상 출력, 출력 예시와 결과 해석, 추가 실험
5. **로그 수집 적용:** 같은 개념을 장비 로그 수집 파이프라인에 적용할 때의 판단 기준
6. **이해도 확인:** 자주 묻는 질문, 퀴즈와 해설, 학습 완료 기록
7. **공식 자료:** Apache Kafka·PostgreSQL 등 공식 문서

`부록/`에는 필요할 때 찾아보는 참고 자료가 있습니다. CLI와 Kafka UI 사용법(A1), Kafka Connect·Schema Registry·Spring Kafka 같은 생태계(A2), 검색할 수 있는 용어집(A3)입니다.

작은 화면에서는 구조도 아래 **크게 보기**로 SVG 원본을 열어 확인하세요. SVG 이미지를 저장해 개인 학습 기록에도 사용할 수 있습니다.

완료 기록은 브라우저의 localStorage에만 저장합니다. 브라우저 데이터 삭제나 주소 변경 시 기록이 달라질 수 있으며, 실습 데이터와는 연결되지 않습니다.
시뮬레이터는 설명용 모델입니다. 실제 Kafka 동작을 확인하려면 반드시 대응하는 [실습](../실습/README.md)을 실행하세요.

소스를 수정할 때 HTML을 직접 수정하면 다음 생성 시 덮어씁니다. 내용은 `tools/content/`(단원별 파일과 부록), 출처 목록은 `tools/course_content.py`, 템플릿은 `tools/build_theory.py`, 디자인/상호작용은 `이론/assets/`에서 수정합니다.
