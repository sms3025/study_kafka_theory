BEFORE YOU START

준비는 가볍게, 관찰은 꼼꼼하게.

JSON과 기본 프로그래밍 지식, 실행 중인 Docker Desktop이면 시작할 수 있습니다. Java 21과 Maven은 컨테이너로 제공합니다.

  1. 예상 결과를 먼저 적습니다.
  2. 실행 로그의 key · partition · offset을 비교합니다.
  3. 장애를 만들고 재시작해 결과를 설명합니다.

12단원 첫 학습 약 11.5시간 + 반복 실험·최종 프로젝트. 권장 속도는 주 2단원, 총 6주입니다. 설치·디버깅 시간은 별도입니다.

ONE PROJECT, MANY LESSONS

주문 이벤트 하나로 끝까지 연결합니다.

OrderEvent → Producer → Kafka → Consumer.
여기에 중복 방지, 실패 기록, DB Outbox와 Streams를 더해, 정상 동작과 복구를 함께 익힙니다.
